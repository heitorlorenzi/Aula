# Aula - Desenvolvimento de Aplicações Web

## Projetos

- `cardapio-digital/` — Versão HTML/CSS/JS puro (Unidade 1)
- `cardapio-react/` — Versão React + Vite + TypeScript + Tailwind (Aula 2.2)

## Como rodar o projeto React

```bash
cd cardapio-react
npm install
npm run dev
```

Acesse http://localhost:5173
